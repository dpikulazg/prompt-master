
The AI prompt generation engine translates the user's current game situation into a highly optimized context sequence for a specific AI agent (ChatGPT, Claude, Gemini, etc.).


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
